Dedicated server administration

Choose Counter-Strike or Half-Life, a map, the player limit, network mode, port, server name and RCON password in the startup window. Start launches the selected game with these settings.

Server settings

The main page shows the current game, address, players and uptime. Select an editable setting and choose Edit. The map-cycle editor changes the ordered list used for subsequent maps. The configuration page exposes the selected game's server variables.

Internet/LAN and Secure are requests. Provider initialized, connected and secure-active values report the engine provider's current state separately. A secure request does not prove authentication or active protection. A nonzero provider failure code indicates the last observed connection failure; inspect the console for details. A provider restart request requires a clean server shutdown and relaunch.

Players, bans and console

The Players page supports kicking or banning selected players. The Bans page supports adding, removing, changing and importing bans from a local configuration file. Check the selected identity and duration before applying a ban.

The Console page shows server output and accepts engine commands. For example, status prints current server information. Commands run with server-administrator privileges. The Graphs page displays periodic engine statistics.

Settings and shutdown

On macOS, server settings and dialog layout are stored in the per-user CounterStrikeExtended/hlds preference directory as Server.vdf and DialogConfig.vdf. Game configuration and map-cycle files remain managed by the game's filesystem.

Use the server window's close action and confirm stopping the server. The launcher retires admin requests and closes its dialogs before unloading the engine. If startup fails, inspect the diagnostic and retry after correcting the reported resource or provider problem.
