# Executable socket ownership regressions

These fixtures compile the actual native socket producer and executable owner, plus extracted actual NET_IPSocket and terminal network-state bodies. They never initialize Steam or a game/session. The focused dylib proves only its own physical unmap; it does not establish hardware engine TLS retirement or actual initialized software acceptance.

Configure with CMake, build with `--parallel 1`, then run CTest serially. The initial RED log is retained separately in the task build tree. Fork/exec tests use owned ephemeral loopback sockets and normal child completion. Syscall redirection exists only in test compilation of the actual owner TU; it supplies failures and deterministic gate overlap without adding production hooks. Instrumented callback-entry counters prove all role checks precede the first host call. Consumed-close error case observes truthful retained failure, exits the isolated test process normally, and makes no successful-retirement claim.

`owning_negatives.py` takes the real full-build compile database and mutates copied actual declarations/initializer under the actual launcher recipe. Production `cse_socket_abi_evidence` independently checks all four real owning recipes and current include/source/policy closure on every build. Actual initialized three-cycle SDK qualification remains controller-owned.
