# Shared network declarations

Compile the actual API and network headers in both include orders. The checks
cover source identifiers, the legacy 20-byte connectionless address with its
port at byte18, integer qboolean constants, compile-time array counts and the tagged eight-byte
mouse callback record with two signed 32-bit coordinates. Windows
keeps its existing declaration; POSIX consumers share the retained common enum.
No packets are sent and no network interoperability is claimed by this fixture.
