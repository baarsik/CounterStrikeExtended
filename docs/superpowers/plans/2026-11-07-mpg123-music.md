# libmpg123 Music Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Miles music with source-built libmpg123 and SDL3 while preserving controls.

**Architecture:** CCDAudio delegates playback to a synchronized decoder/SDL stream backend.
Upstream mpg123 is built as a shared dependency from a pinned source archive.

**Tech Stack:** C++17, SDL3 3.4.20, mpg123 1.33.7, CMake/MSBuild, VM1 Windows x86.

**Spec:** docs/superpowers/specs/2026-11-07-mpg123-music-design.md

## Global Constraints

- Preserve commands, track mapping, fades, focus policy and physical CD support.
- No copied Xash GPL integration code; preserve mpg123 LGPL materials.
- Windows x86/MSVC v145 and SDK 10.0.26100.0 remain the production target.
- Regenerate target definitions from retained manifests; test on VM1.

## Review Focus

- EOF with a partially filled decode buffer must not lose audio.
- Looping an empty/corrupt file must not spin indefinitely.
- Track replacement/shutdown must not race decoder or SDL stream destruction.
- Audio subsystem ownership must coexist with other SDL consumers.
- No Miles provider may be borrowed from game data during qualification.
