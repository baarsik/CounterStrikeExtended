- Implement actual console and retained GUI/admin functionality. Headless startup alone is an intermediate milestone.
- Preserve maintained Win32 and native Windows x64 behavior, interface slots, fixed-width messages and per-file policies.

- No Windows API success shims, fake HANDLE, disabled GUI, renamed hardware engine, admission bypass, truncated pointers/block widths or fabricated provider success.
- Engine module/cohort admission precedes callback exchange; validate actual factory/view/vtable and role before virtual calls. Keep all callback targets and images alive until quiescence.
- Preserve protocol48, game algorithms, network/disk encodings, CS and Half-Life, real stdin/stdout and retained resources/configuration/admin commands.
- Manifest or translator edits own generated inventory changes; run `python3 tools/translate_msbuild.py`. Do not independently patch generated CMake.
- New/edited C++ follows root AGENTS.md: four spaces, braces, named domain constants, one declaration/statement per line and narrow formatting.
- Work in a fresh isolated worktree seeded from the controller's immutable current-root snapshot. Do not overwrite dirty root migration work or operate shared root apps/builds/VMs from an implementer. Controller owns integration and authorized shared runtime testing.
- Complete ARM64 Release/Debug actual graph and runtime checks, then changed Windows x86/x64 owners under retained policies. Source plans and component doubles are not acceptance.

## Review Focus

1. Valid long argv accepted by common parser may overflow the dedicated engine's 1024-byte command storage; rejection must occur before any copy/Init.
2. EOF after piped startup commands must neither spin nor kill a service; a final unterminated line executes once and signals still terminate cleanly.
3. Closing a popup or admin page during dispatch must prevent callbacks/events from reaching retired objects or reused handles.
4. Failed engine/VGUI/provider initialization followed by retry must retain no old callback, partially mounted filesystem, worker or stale factory.
5. Native file dialogs and HiDPI windows must work with root paths, empty directories, UTF-8/spaces, focus/capture and resized backing buffers.

## Required software-engine lifetime dependency

The completed software-engine phase must supply public/native_dedicated_lifetime.h and actual CseNativeDedicatedRetireV1(uint32_t)->uint32_t export. Native hlds must require this versioned boundary alongside its admitted engine API, keep ordinary API Shutdown reusable for admin stop/start, and invoke final retirement only after completed Shutdown outside the loader lock. Ready/AlreadyRetired permit unload; every other result prevents unload. Final retirement is terminal for that image's dedicated API. Cover missing export, wrong version, active/partial rejection, double retirement, post-retire Init rejection and actual repeated provider/module unload with clean process exit. Do not replace this with a destructor-only close, unchecked optional fallback, engine residency leak or forced-success process exit. See the software-engine plan amendment and root headless evidence for the actual stale-cache/Steam failures that required it.
