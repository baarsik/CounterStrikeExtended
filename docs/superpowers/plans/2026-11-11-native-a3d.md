# Native A3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. The controller dispatches one implementation owner at a time. Steps use checkbox (`- [ ]`) syntax for tracking. No helper agents or overlapping source ownership without an explicit controller assignment.

**Goal:** Deliver the retained native A3D software/API/module with real native device/lifetime ownership and qualified stock software behavior, while preserving explicit OEM and game-consumer gaps.

**Architecture:** Keep all retained geometry/source/mixer units and public interface families. Implement an owned native software facade, real buffers, typed resource injection and SDL output using the actual A2D control/kernel/table behavior. Preserve the default engine mixer and the existing Windows external-provider routes.

**Tech Stack:** C++17, CMake 3.25+/Ninja, pinned SDL3 3.4.20, macOS 14+ ARM64/Clang and maintained Windows SDK/MSVC layouts/policies.

**Spec:** `docs/superpowers/specs/2026-11-11-native-a3d-design.md`. Reference evidence: `build/macos-runtime-bringup-20261109/a3d-reference-analysis-v1/{findings.md,controller-checks.json,selected-evidence.json}`. Read both spec and evidence before executing.

## Global Constraints

- All 21 retained TUs stay selected, including the five generated geometry sections. Preserve each TU's FP/EH/optimization/CRT/assertion/diagnostic policy and both Windows paths; new source/policy selection originates in the manifest/translator and is regenerated.
- Existing public slots, scalar/GUID/record widths and full-width private identity stay unchanged. No pointer enters the legacy DWORD initialization lane; use existing `IA3dNativeDeviceV1`.
- Stock software `SetSuperCtrl` success and no effect for unread EQ/reflection fields is the reference behavior. Do not add arbitrary DSP or reject a valid low-level record merely because those fields are populated.
- Public native capability negotiation is separate: only qualified rendering is advertised. Do not fabricate successful OEM/reflection requests, hardware caps, driver IDs or Windows activation.
- Preserve the engine default mixer, music, voice and VOX paths. No new engine A3D bridge or default feature selection is part of this plan.
- Global compiler concurrency cap is **2**. The future A3D implementation owns **1** compiler slot unless the controller explicitly allocates more within that cap. All commands here use `--parallel 1`; no nested/unbounded/background build.
- `dedicated_host` remains the sole production implementer until the controller releases and assigns ownership. These canonical docs are preparation, not an implementation dispatch. Do not mutate existing build/app/provider/VM/Steam/assets from a source-only task.
- Use new owned build directories and the already available dependency configuration. No new worktree or dependency installation is implied. Controller owns scoped commits/integration; never stage the broad dirty root from a task agent.
- Native notifications use only the distinct V1 typed event/notify ABI in the spec; preserve Windows HANDLE behavior and explicitly reject the legacy view on Mac. Implement and test native functionality, not just rejection.
- CPU tests, actual-module tests, actual-device tests, OEM tests and game-consumer tests are distinct. A skipped/unavailable external test is not a pass.

## Review Focus

1. Parent release, event close or registration replacement while a waiter re-enters a live buffer: retain needed state/module, fence old signals and avoid callbacks under owner locks (tasks 3, 5, 7).
2. Format/size/cursor inputs wrap or use addresses above 4 GiB: reject overflow before access and retain correct production-owned history (tasks 1, 4).
3. SDL open/resume/device failure or repeated initialization: fail accurately, unwind every acquisition and preserve another audio user's subsystem reference (tasks 2, 5, 8).
4. Multiple software instances render concurrently: shared scratch and render/control state cannot race or change deterministic PCM (tasks 4, 5).
5. Low-level ignored fields are confused with supported public acoustic features: pin stock invariance and separately prove capability rejection/negotiation (tasks 6, 7).

The facade invokes the existing typed `IA3dNativeDeviceV1::InitializeDevice(const GUID*, DWORD, DWORD, DWORD*)` on its initialized software leaf and injects that leaf into `ResMan`. `AttachNativeBackend` never calls `A3dCreateNativeProvider`, never re-enters the exported factory and never sends a pointer through `InitializeEx`. The native owning facade exposes the existing API views, while legacy Windows construction retains OEM activation. This resolves the two independent activation sites without a recursive object graph.
