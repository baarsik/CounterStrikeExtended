## Native dedicated final lifetime amendment

Actual two-session tests exposed stale model-cache pointers into a released heap, a shutdown-completed guard that skipped the second cleanup, and Steam transport retirement after vendor finalizers or under dyld's loader lock. Task1 must repair these real owning lifetimes, including the shared Mac full-host drain/Steam shutdown order that also affects client early quit. This expands its file seam to host.cpp, model.cpp, common/steam_service.cpp, public/steam_service.h and public/native_dedicated_lifetime.h; no gameplay or command-buffer algorithm changes.

The Apple software engine must export CseNativeDedicatedRetireV1(uint32_t interfaceVersion) returning named uint32_t results. Version1 requires explicit completed API Shutdown and no active/partial session, retires the actual module-owned Steam transport outside the loader lock, and is terminal for that image's dedicated API. Ready and AlreadyRetired are idempotent host completion; other results prohibit unloading. Ordinary API Shutdown remains reusable across admin stop/start. The real native host and harness must require this boundary before dlclose. No virtual slot changes, unchecked optional fallback, forced-success exit or raw-dlclose hang qualifies. Cover wrong version, active/partial rejection, double Shutdown/retire, post-retire Init rejection, repeated real provider module unload and actual process exit.
